## 2. 금지 — 위반 시 즉시 반려

### 2.1 도구의 한계를 대상의 성질로 바꾸는 것 — **오늘 가장 위험한 오독**

| ✗ 금지 | ○ 허용 |
|---|---|
| 고령자가 대표기능에 도달할 수 없다 | 본 연구의 자동 관측 프로토콜 범위에서 도달 가능한 경로로 관측되지 않았다 |
| 대표기능이 로그인 뒤에 있다 | 초기 화면에 로그인 관련 텍스트 후보가 존재해 계정행동 가드가 탐색을 중단시켰다 |
| 진입 깊이가 깊다 / 얕다 | 진입 깊이는 산출되지 않았다 |
| 서비스가 접근을 막는다 | 우리 수집기가 그 지점에서 탐색을 중단했다 |

**가드는 "단어가 있다" 를 탐지했지 "대표기능이 gate 뒤에 있다" 를 확인하지 않았다.**
그 확인을 하려면 gate 를 통과해야 하고, 통과는 금지돼 있다. **우리는 원리적으로 모른다.**

### 2.2 실제 고령자에 대한 주장

본 연구는 실제 고령자의 행동실패·포기·lostness·학습효과·AI intervention 효과를
**직접 관측하지 않았다.** 어떤 결과도 그것을 말하지 않는다.

### 2.3 인증제도에 대한 주장

variance 0 이므로 **비교 자체가 성립하지 않았다.** *"인증제도가 놓쳤다"* 금지.
허용은 *"본 프레임에서 현행 인증과의 비교가능한 overlap 이 없었다"* 뿐이다.

### 2.4 인과·점수

인과표현 금지. 단일 종합점수 금지. joint profile 을 "score" 로 부르지 않는다.

### 2.5 N 을 숨기는 서술

*"대부분의 서비스가…"* 같은 표현을 **N 과 분모 없이** 쓰지 않는다.
오늘 N 은 작고, 그 사실이 모든 문장에 따라다녀야 한다.

### (b) 검증 실수의 구조적 패턴 — **7건이 같은 축이었다**

오늘 B 4건 · A 3건의 오류가 발생했고 **전부 같은 형태**다:

> **손에 원본이 있는데 형식·범위를 확인하지 않고 비교하거나 일반화했다.**

| 사례 | 형태 |
|---|---|

| 시각을 셸에서 읽지 않고 앞선 메시지에서 외삽 | 유도값 사용 |

**개인의 부주의가 아니라 "빠르게 판단해야 할 때 무엇을 생략하게 되는가" 의 구조적 패턴이다.**

### (c) 3중 독립 검증이 실제로 작동한 지점

```
축 C 계수 12종        A · B · C 서로 다른 시점·경로
```
