### 5.1 `min-4-selector-tiebreak-does-not-neutralize-subpixel-jitter` — P2

**차단 범위: P-C / `E000_V2`. `V2_SSOT_FROZEN` 비차단.**

A1 §2.6 MIN-4 의 근거 문장:

> `area_css_px2`는 `getBoundingClientRect`에서 오는 부동소수이며 … 서브픽셀이 흔들리면
> **근소한 동률이 런마다 뒤집힌다.** `selector` 문자열 오름차순은 그 흔들림에 영향받지 않는다.

**뒷문장이 실제보다 강하다.** `selector` 는 **세 번째** 키이므로 `area_css_px2` 가 **정확히 동일**할
때만 참조된다. MIN-4 가 이름으로 지목한 바로 그 케이스 — 서브픽셀 jitter 로 생기는 *근소한 동률* —
에서는 면적이 다르므로 `selector` 에 도달하지 못하고 순서는 여전히 뒤집힌다. 재현:

```
JITTER run1 MIN-4 : ['div>ul>li:nth-of-type(1)>a', 'div>ul>li:nth-of-type(2)>a']
JITTER run2 MIN-4 : ['div>ul>li:nth-of-type(2)>a', 'div>ul>li:nth-of-type(1)>a']   # 0.01 px² 차이
```

MIN-4 는 **완전 동률 부분케이스만** 고친다. 겹치는 문제로, §2.5 가 이 규칙에 붙인 검증 케이스가
*"같은 fixture를 두 번 돌려 같은 경로가 나오는가"* 인데 fixture 는 결정적이고 폰트 로딩·리플로우
jitter 가 없으므로 **현행 2키 엔진에서도 통과한다** — 규칙이 막으려는 실패 양상을 구조적으로
탐지할 수 없는 검증이다.

MIN-5 가 이것을 덮지 않는다. MIN-5 의 세 좁힘은 **부분격자의 크기**에 관한 것이지
**run-to-run 결정성**에 관한 것이 아니다.

또한 TARGET 에 §2.6 을 LANE C 에 묶는 것이 없다 — 엔진 브랜치의 A1 사본에 `MIN-4` **0건**,
§7 에 "엔진이 `selector` 를 3차 정렬키로 추가한다"를 추적 산출물로 세운 행이 없다.
등재된 유일한 검사가 실패할 수 없는 fixture 재실행이다.

**처방(P-C):** `selector` 키 **앞에서** `area_css_px2` 를 양자화(정수 px² 또는 허용오차 밴드)하고,
결정성 검증을 fixture 재생이 아니라 실대상 또는 jitter 주입 재실행으로 바꾼다.
A1 §7 에 엔진 측 이행 의무를 한 줄 등재한다.

**왜 항목 7 을 열어두지 않는가** — 원 finding 은 *최소성이 조작화되지 않았다*였고 조작화는
실제로 이뤄졌다(탐색 절차·전순서·범위 한정·자기신고 편향). 이것은 그 조작화 안의 **한 규칙이

### 5.2 `rc-5-anchor-verification-report-row-still-scoped-to-recollection-runs` — P2

**차단 범위: `E001_V2` 보고(RC-5 / 조건 C-4). `V2_SSOT_FROZEN` 비차단.**

C-2 의 (a) 채택으로 **강제 층**은 최초 run 까지 정확히 넓어졌다(§6.3 가드 `A2:2560` 이

확인될 때에만"). 그런데 **RC-5 보고 표의 두 행이 옛 범위 표기 그대로다.**

```
A2:1462 | 앵커 검증 결과 | 재수집 run별 RC-6 검사 A-1~A-8 통과 여부. 실패 run 수는 0이어야 한다 |
A2:1460 | 실행 인가 대조 | … 제출된 재수집 evidence run 수. 세 수가 같아야 한다 … |
```

강제 층은 최초 run 에 A-1~A-8 을 걸고 `EXECUTION` 레코드를 요구하는데, 보고 표는 그 결과를

실리지 않고, (ii) `E` ↔ `EXECUTION` ↔ 제출 run 3수가 **정의상 어긋난다** — `E` 는 최초 run 인가를
포함해 세는데 제출 run 수는 재수집만 세기 때문이다. **이 3수가 바로 내가 조건 C-4(i)·(ii)에서
두 감사에게 대조하라고 지정한 수**다.

이것은 실질 탈출구가 아니다(X-14 ⑨ · RC-4 확대 · §6.3 가드가 전부 최초 run 을 묶는다).
**보고 층과 강제 층의 범위 불일치**이며, 그대로 두면 C-4 대조가 성립하지 않는다.

**처방:** `A2:1462` 와 `A2:1460` 의 `재수집` 한정을 걷어내고 "재수집 run 과 최초 run 을 합쳐 센다"로
정정한다. 두 줄이다.
