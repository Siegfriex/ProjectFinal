## 3. 확인 1 — MIN-4 양자화 `16px²`: 지시받은 (a)~(d)

### 3.1 (a) `16px²` 가 내가 시험한 노이즈 규모에서 flip 률을 낮추는가 — **아래쪽 끝에서만**

run-to-run 경로 flip, `N = 40000`. jitter 격자는 두 가지로 돌렸다 —
Chromium LayoutUnit(`1/64 px`) 과 연속. `raw` = 양자화 없음.

연속 격자에서도 같은 형상이다(`Δw=0.01` 에서 `16px²` 는 1.1~13.9%, `Δw=0.5` 에서 42.0~50.0%).

**세 가지를 말한다.**

1. **`Δw = ±0.01px` 에서 `16px²` 는 실제로 듣는다.** `1px²` 가 카드급에서 개선 0이던 자리를
   `49% → 7~29%` 로 내렸다. 내 반증의 이 대역은 **실질적으로 해소됐다.**
2. **`Δw = ±0.05px` 에서는 카드·히어로에 대해 사실상 듣지 않는다**(`50% → 35~45%`).
3. **`Δw = ±0.5px` 에서는 전 형상 개선이 0이다**(`50% → 49~50%`). **`1px²` 때와 동일한 수치다.**
   문서는 내 `±0.5px` 결과를 `1px²` 를 버리는 **근거로 인용**했는데, 새 값도 그 대역에서
   똑같이 무력하다는 사실은 적지 않았다. 독자는 그 실패가 시정됐다고 읽는다.

### 3.2 (b) `16px²` 가 너무 커서 다른 크기의 control 이 묶이는 반대 비용 — **거의 0. 그리고 그것이 문제다**

먼저 지시받은 질문에 답한다: **반대 비용은 받아들일 만하다. 사실상 존재하지 않는다.**

`16px²` 가 병합하는 것은 면적 차이가 `16px²` 미만인 쌍이고, 이를 **선형 폭 차이**로 환산하면:

| control | `16px²` 에 해당하는 폭 차이 | `1px` 실제 차이의 면적 |
|---|---|---|
| 히어로 335×220 | **0.073 px** | 220 px² |
| 2열 카드 171×120 | **0.133 px** | 120 px² |
| CTA 335×48 | 0.333 px | 48 px² |
| nav 88×44 | 0.364 px | 44 px² |
| 아이콘 24×24 | 0.667 px | 24 px² |

즉 `16px²` 는 **어느 형상에서도 `1px` 의 실제 레이아웃 차이를 병합하지 않는다.** 반대 비용은 0이다.

**그러므로 문서가 `16` 을 정당화하려고 든 두 문장이 둘 다 틀렸다.**

> `16px²`는 `4×4px` 규모의 실제 레이아웃 차이에 대응한다 — 그보다 작은 차이는 동급 control 사이에서 의미를 갖지 않는다. (`A1:407`)

`16px²` 는 고립된 정사각형의 면적으로 읽을 때만 `4×4px` 다. **두 control 사이의 차이**로 읽으면
`171×120` 카드에서 `0.13px`, 히어로에서 `0.07px` 다. 이것은 내가 `V2-C009` 에서 지적한
**면적 단위와 선형 단위의 범주 혼동과 정확히 같은 오류**이며, 이번에는 반대 방향으로 났다.

> 단위를 키우면 그 확률은 줄지만 **실제로 다른 크기의 control 이 같은 버킷에 묶이는** 반대 비용이 커진다. 이 교환은 P-D 의 판단 사항이다. (`A1:409-412`)

이 교환은 **`16` 에서 구속하지 않는다.** 구속이 시작되는 지점은 가장 작은 control 이 정하며
(`24×24` 아이콘의 `1px` 차이 = `24px²`), 그 위쪽 천장은 `Q ≈ 24px²` 다.

**그리고 여기서 절대 양자의 불가능성이 나온다.**

```
±0.5px 선형 jitter 를 중화하려면        Q >> 277 px²   (히어로 335×220)
24×24 아이콘의 1px 실제 차이를 보존하려면  Q <=  24 px²
                                        → 11배 이상 모순. 양립 불가.
```

`Δw = ±0.05px` 로 낮춰도 히어로의 면적 jitter 는 `27.75px²` 로 이미 아이콘 천장을 넘는다.
**어떤 절대 면적 양자도 두 제약을 동시에 만족할 수 없다.** P-D 가 숫자를 고르는 문제가 아니다.

**닫을 수 있는 형태는 존재한다** — `V2-C009` 닫는 조건 1(ii) 그대로, `w`·`h` 를 먼저 선형 양자화한 뒤 곱한다.
같은 시뮬레이션(연속 격자, 위상 무작위화, `N=40000`):

| 선형 양자 `LQ` | nav | 카드 | 히어로 | 아이콘 | (`Δw = ±0.5px`) |
|---|---|---|---|---|---|
| `1px` | 27.0% | 26.5% | 26.8% | 26.9% | 형상 무관 — **스케일 정합** |
| `2px` | 13.5% | 13.7% | 13.1% | 13.2% | |
| **`4px`** | **0.0%** | **0.0%** | **0.0%** | **0.0%** | |

`LQ = 1px` 에서 `Δw=0.01/0.05/0.5` 의 flip 률이 전 형상 `0.5% / 2.7% / 27%` 로 **형상에 무관하게 같다**.
이것이 "스케일 정합"의 의미다 — 절대 면적 양자는 형상마다 다른 답을 주고, 선형 양자는 주지 않는다.
`LQ` 는 목표 flip 률에서 역산하면 되고(`LQ ≳ 4Δ` 에서 0), `1px` 실제 차이 보존은
`LQ ≤ 1px` 또는 `LQ` 를 동결값으로 공표하는 것으로 처리된다.
