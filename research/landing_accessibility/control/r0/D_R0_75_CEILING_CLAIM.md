## §2 (1) — B 의 구조적 주장은 n=16 에서 성립하지 않는다

```
12/16 = 0.750
Wilson 95% CI [0.505, 0.898]  ∋  0.85
```

**`0.750` 은 점추정이고 `0.85` 는 그 신뢰구간 안에 있다.**
`D-R0-54`(겹침 16건)를 발주할 때 A 가 `OVERLAP_AGREEMENT_REPORT §4` 에 이미 적었다 —
*"n=16 의 CI 가 넓어 prior-label 0.5238 과도 구분되지 않는다."*
**같은 n 이 이번에는 반대 방향으로 쓰였을 뿐 넓기는 마찬가지다.**

```
DECISION  "게이트가 인간 상한보다 높다" 를 근거로 쓰지 않는다.
          그 주장을 하려면 겹침 표본을 늘려 CI 하한이 0.85 를 넘지 못함을 보여야 한다
```

## §3 (2) — 지금의 binding constraint 는 coverage 다. 이것이 가장 유용한 관측

```
겹침 16건에서 detector(v3 prior_only)
   AMBIGUOUS  13 / 16
   매핑        3
```

**3건 위에서 계산한 agreement 는 의미가 없다.** C 가 *"consensus 12건 대비 보조지표는 n=1 이라 무의미"* 라고
쓴 그대로다.

```
현재 사실   'agreement 기준이 너무 높다' 가 아니라 'detector 가 대부분 abstain 한다'
```

**그리고 이것이 `D-R0-74-2` 를 강화한다.** `D-R0-13` NLP fallback 은 **ambiguity 를 푸는**
계약된 장치다 — abstain 을 정당하게 결정으로 바꾸는 유일한 경로이며, 아직 밟히지 않았다.

```
DECISION  R1(detector 부족) 과 R2(DOM 정보 부족) 을 지금 판정하지 않는다
이유      coverage 가 이 수준일 때 둘을 구분할 수 없다.
          detector 가 81% 를 abstain 하는 상태에서 'DOM 에 정보가 없다' 는 결론은 이르다
판정 시점  D-R0-13 fallback 을 밟은 뒤. 그때 coverage 가 오르고도 agreement 가 낮으면 R1/R2 판정에 들어간다
```

## §4 (3) — 기준은 그대로 둔다

```
0.85 / 0.75 유지. W2 는 FAIL 로 남는다
```

`D-R0-64` 의 `prereg_defense_line` 이 이 상황을 위해 있었다 —
**무인 진행 중에는 기준을 바꾸는 것을 지적할 사람이 없다.**
지금 B 도 C 도 A 도 기준 변경을 제안하지 않았고, 그것이 이 교환에서 가장 중요한 사실이다.
