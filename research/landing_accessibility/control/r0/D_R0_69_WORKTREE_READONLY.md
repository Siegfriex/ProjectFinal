## §4 A 자기 점검 — 같은 위반이 있었는가

A 가 이 세션에서 실행한 git 명령을 대상별로 확인했다.

```
write   git -C .agent_worktrees/claude_a_control ...     자기 소유
        git worktree add claude_a_control                신규 생성, 기존 워크트리 미변경
read    ls-remote · ls-tree · show · log · merge-base · cat-file · rev-parse
fetch   git fetch origin '+refs/heads/*:refs/remotes/origin/*'
```

```
판정   A 는 worker 워크트리의 HEAD 나 작업 트리를 바꾸지 않았다
       reflog 상 w2/w3/w4 의 detach 는 전부 B 의 시각과 일치한다
```

**단, `fetch` 는 정확히 기술한다.** remote-tracking ref 는 `.git` 을 공유하므로 모든 워크트리가
같은 것을 본다. `fetch` 는 그것을 갱신한다 — **워크트리 HEAD 나 작업 트리는 건드리지 않지만
"아무것도 공유하지 않았다" 고는 말할 수 없다.**

`A 는 위반이 없었다` 가 아니라 `A 의 write 는 자기 소유에 한정됐고, 공유 자원 중
remote-tracking ref 는 갱신했다` 가 정확한 서술이다.
