## §4 DECISION

### D-R0-78-1 — PASS 와 FAIL 은 제외에 대해 비대칭이다

```
FAIL   제외 항목이 있어도 유효하다
       측정 가능한 항목 중 하나라도 미달이면 criterion 은 미달이다.
       못 잰 항목이 그것을 되돌릴 수 없다

PASS   제외 항목이 하나라도 있으면 성립하지 않는다  →  UNDETERMINED
       못 잰 항목이 미달이었을 수 있다. PASS 는 '충족했다' 는 주장이고
       그 주장의 근거가 부분적으로 없다
```

**이 비대칭이 자의적이지 않다.** `FAIL` 은 **존재 주장**(미달 항목이 있다)이고
`PASS` 는 **전칭 주장**(모든 항목이 충족한다)이다. **전칭 주장은 표본 누락에 취약하고
존재 주장은 그렇지 않다.**

### D-R0-78-2 — `PASS_MEASURABLE_ONLY` 를 만들지 않는다

C 가 대안으로 제시한 별도 상태를 채택하지 않는다.

```
이유   정직한 이름이지만 하류에서 PASS 로 집계된다.
       'PASS' 라는 토큰이 이름 안에 있는 한 어딘가에서 PASS 로 세어진다
       SSOT §9 는 이미 UNDETERMINED 를 이 용도로 갖고 있다 — 새 상태가 필요 없다
병기   제외 비율은 UNDETERMINED 의 부기로 남긴다.
       '왜 UNDETERMINED 인가' 를 잃지 않기 위해서다
```

### D-R0-78-3 — `ratio ≤ 1.05` 의 지위

```
요구   refcohort 코드북에서 'ratio ≤ 1.05 = 측정불가' 의 근거를 인용으로 제시한다
근거 없으면   이 조건을 측정불가 집합에서 제거한다
기본값        fg_alpha 1 이고 bg 가 확정된 항목의 ratio 1.0 은 측정 결과다.
              측정 실패로 취급하지 않는다
```

**`ratio 1.0` 은 "잴 수 없었다" 가 아니라 "재보니 1.0 이었다" 이다.**
흰 배경의 흰 글자는 측정 실패가 아니라 **접근성 실패**다.
