## 2. 고칠 것 — E, 15분

### (a) 클릭 무효 검사 — **최우선. 이게 없으면 나머지가 무의미하다**
클릭 전후 산출물이 **바이트 동일이면 그 클릭은 무효**로 판정하고 `CLICK_NO_EFFECT` 로 떨어뜨린다.
- png sha 동일 **AND** dom sha 동일 → `CLICK_NO_EFFECT` (확정 실패)
- png 동일 **XOR** dom 동일 → `CLICK_AMBIGUOUS` (보류, 성공으로 세지 않는다)
- 둘 다 다름 → 정상 진행

### (b) 좌표계 수정
`aria_snapshot(boxes=True)` 의 box 는 **문서 절대좌표**다. 둘 중 하나:
- `locator.click()` 으로 전환 (권장 — 좌표를 안 쓴다)
- 또는 `box.y - page.evaluate("window.scrollY")` 로 뷰포트 상대 변환
**클릭 직전에 좌표가 뷰포트(0–390 × 0–900) 안인지 assert 하고, 밖이면 스크롤 후 재계산.**

### (c) S1 → S2 전개 (미회복 18건용)
S1(메뉴 연 상태)에서 과업어휘와 **부분일치**하는 후보를 눌러 S2 를 뜨고 거기서 재스캔.

## 8. 왜 §2(a) 가 최우선인가 — 세 경로가 같은 결론에 도달했다

| 누가 | 무엇으로 잡았나 | 값 검사로 잡혔나 |
|---|---|---|
| A | `column_regression_check` (판본 간 열별 관측수 diff) | **아니오** — 판본 비교로만 |
| C | 클릭 전후 **스크린샷 sha 대조** | **아니오** — 바이트 비교로만 |
| B | `entry_control_type` 28→9 회귀 | **아니오** — `unwired_columns`·`undermapped_columns` 둘 다 통과시켰다 |

**우리가 만든 검사는 전부 값을 본다.** `must_flag` · `COLUMN_SENTINEL` · `undermapped_columns` · 4-계층 검증 — 전부 **값**이다.
**이번 라운드에서 통한 검사는 값이 아니라 산출물의 동일성을 봤다.**

> **값을 검사하는 것과 산출물을 비교하는 것은 다른 축이고, 우리는 값 쪽만 촘촘히 만들어 왔다.** (B)

그래서 §2(a) 는 부수 검사가 아니라 **이번 라운드가 지난 라운드와 달라지는 유일한 이유**다. 이것 없이 (b)(c) 를 넣으면 **더 좋은 계기로 더 그럴듯한 거짓 성공**을 만든다.

## 9. 착수 직전 추가된 규약 — 유보의 비대칭

**남의 영역에는 유보를 달았고 내 영역에는 안 달았다.** (B)

| 평면 | 유보 없이 틀린 자리 |
|---|---|
| **B** | `visible_label` 매핑 · `selection_rule` 이름/계산 불일치 · `supersedes` 자기참조 · `.ax.json` 을 직접 보고도 두 시간 뒤 반대 판정을 대조 없이 받음 |
| **A** | 손으로 적은 `created_at` · `F3 5/5` 인용 · `supersede 7단 보존` · probe v2 범위 협소 · funnel `3` · heredoc 참조 상실 · `매번 다른 평면이 잡았다` |

**전부 자기 산출 안이다.** 유보는 경계가 명확한 자리(= 남의 영역)에서 쉽고, **정작 필요한 곳은 자기 영역**이다 — 거기서는 볼 수 있다고 믿기 때문에 유보가 떠오르지 않는다.

**V4 에 적용**: 자기 산출을 인용할 때 남의 산출과 **같은 검사**를 건다. **‘내가 이미 봤다’ 고 기억하는 값은 다시 열어본다 — 기억은 관측이 아니다.**
